# Frens with Fam: character SVGs

Two sets of the same eight frens, each in seven growth stages (0 egg, 1 hatchling, 2 baby, 3 kid, 4 teen, 5 grown, 6 legend).

| Folder | What |
|---|---|
| `unisex/` | Classy, goofy, quirky. Muted earthy colours, goofy faces, no blush. |
| `cute/` | The earlier pastel, kawaii set. |
| `*/shaded/` | Ready to view: shading, shine, eye glints and a soft halo baked in. Looks best on a dark background. |
| `*/flat/` | Plain flat shapes, easiest to edit in Figma or Illustrator. |
| `*/preview.png` | Contact sheet of the whole set. |
| `index.html` | Open in a browser to see every file at once. |

Files are named `<fren>/<fren>-<stage number>-<stage>.svg`, for example `unisex/shaded/bloop/bloop-3-kid.svg`.

Each stage has one item no other stage has: hatchling shell cap, baby juice box (rattle in the cute set), kid skateboard (balloon), teen headphones, grown sneakers (rosette badge), legend gold chain and sparkles.

The frens: Bloop, Mochi, Puff, plus five candidates for the fourth (Pup, Berry, Pickle, Chiku, Bun).
All SVGs are self-contained (no fonts, images or scripts). Drafts for Frens with Fam (FamApp), not final art.
